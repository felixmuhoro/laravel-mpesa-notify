# Laravel M-Pesa Notify

Payment notification helpers for Laravel built on top of [felixmuhoro/laravel-mpesa](https://github.com/felixmuhoro/laravel-mpesa).
Sends SMS, email, and webhook alerts on every M-Pesa payment event.

## Installation

```bash
composer require felixmuhoro/laravel-mpesa-notify
```

## Requirements

- PHP 8.1+
- Laravel 10 / 11 / 12 / 13
- [felixmuhoro/laravel-mpesa](https://packagist.org/packages/felixmuhoro/laravel-mpesa) ^1.2
